# Разработка

Python 3.12+, `pip install -r requirements.txt`, затем `python main.py`.

Перед pull request: `python -m pytest -q`. Приложите короткое описание сценария и тест с реальной обработкой файла для изменений движка. Не добавляйте чужие бинарники, пароли, приватные пути и файлы пользователя. Для VRChat не копируйте исходники VRCEmoji: лицензия не указана.
