# Изменения

## 0.9.9 — 2026-10-03

- Удалён тёмный прямоугольник за драконом и названием в шапке боковой панели. Контейнер логотипа теперь показывает тот же фон, что и остальная панель.
- Windows UI-тест сравнивает цвета фона за логотипом и рядом с ним на снимке окна, чтобы ошибка не вернулась.

## 0.9.8 — 2026-10-03

- Ползунок целевого размера перенесён в основную карточку конвертации изображений и видео. При выборе файла видны его размер, процент и цель; для видео показывается расчётный битрейт, а битрейт звука подстраивается под выбранный предел.
- Для PNG и других форматов без настройки качества ползунок тоже работает: если сжатия недостаточно, уменьшается разрешение. Цель может быть недостижима для очень маленьких файлов; приложение сообщает об этом при обработке.
- «Видео → GIF» перенесено в раздел «Видео». Раздел изображений принимает только изображения, а список действий в каждом разделе ограничен подходящими операциями. На главной формат JPEG/PNG подставляется из выбранного файла, если пользователь не выбрал свой формат или пресет.
- Добавлены проверки видимости ползунка, переходов между разделами, распознавания JPEG/PNG и достижения размера при обработке PNG.

## 0.9.7 — 2026-10-03

- Исправлен общий вылет при наведении и нажатии кнопок редактора: Qt теперь использует одного рисовальщика на кнопку. Проверка собранного EXE воспроизводит сочетание анимации наведения и нажатия для всех пяти проблемных кнопок.
- Добавлены проверки действий «Добавить», «Папка», «Удалить выбранные», «Информация» и «Preview / Crop» после загрузки PNG.
- Левая панель получила более ровные отступы, компактные пункты и отдельную карточку. Вверху появляется индикатор новой версии.
- Проверка версий выполняется при запуске и раз в час, если её не отключить. При новой версии показывается сообщение и уведомление Windows. Автоматическое скачивание включается отдельно; файл проверяется, а установка запускается только по нажатию.

## 0.9.6 — 2026-10-03

- Исправлен вылет при нажатии «Добавить»: окно выбора файлов и папок открывается встроенным диалогом Qt, без вызова системного диалога Windows. Проверка собранного EXE нажимает кнопку и добавляет PNG.
- Значок Windows перекодирован с прозрачностью в стандартные BMP-кадры ICO. Сборка проверяет извлечённый значок у Portable EXE и установщика, чтобы не выпустить файл со старой подложкой.
- При аварийном завершении Python записывает стек в `logs/crash.log` рядом с настройками приложения.

## 0.9.5 — 2026-10-03

- Логотип приложения и значок Windows без квадратной подложки, с прозрачным фоном.
- Изменения размера и параметров отражаются в предпросмотре; для видео сравнение текущего кадра запускается автоматически. Ползунок задаёт целевой размер относительно исходного файла.
- Кнопка «Конвертировать сейчас» запускает обработку без перехода в очередь и открывает готовый результат в истории. В очереди доступны последние результаты, в истории — все завершённые задачи; для изображений есть сравнение до/после, для видео и GIF — переключение файлов.
- Разделы отклоняют несовместимые файлы, в том числе при перетаскивании; исправлены чёрные полосы настроек и узкое окно «О программе».
- Компоненты можно устанавливать и удалять по одному либо пакетом. Установка показывает ход работы и поддерживает отмену. Добавлен отклик на нажатие кнопок.

## 0.9.4 — 2026-10-03

- Исправлены проверки Windows: чтение UTF-8 в Inno Setup и сравнение временных путей к Portable-приложению. Функции выпуска 0.9.3 включены в этот пакет.

## 0.9.3 — 2026-10-03

- Сравнение исходника и результата ползунком для фото, а также сравнение текущего кадра видео с настройками FFmpeg до запуска конвертации.
- Замок пропорций связывает ширину и высоту; готовые размеры заполняют редактируемые поля. Одни параметры применяются ко всем файлам в очереди, количество задач видно заранее.
- В настройках автоматически проверяются новые выпуски, включая предварительные; обновление скачивается с проверкой размера и контрольной суммы GitHub. Setup запускает установщик, Portable заменяет файлы после закрытия программы, сохраняя `data`.
- У установки компонентов через WinGet появились ход процесса, отмена и подробный вывод ошибки. Версия установщика синхронизирована с версией приложения.

## 0.9.2 — 2026-10-03

- Встроенный просмотр изображений и GIF; воспроизведение видео и аудио с паузой и прокруткой через системный Qt Multimedia. Для статичных изображений предпросмотр показывает crop, поворот, отражение и размер до запуска задачи.
- Размеры, FPS и параметры аудио считываются из исходного файла и появляются в редакторе. Подробности файла всегда видны под просмотром; значения можно изменить.
- Дополнительные поля зависят от выбранного действия и формата. FPS не показывается для JPEG, параметры кодирования скрыты при remux. Каждое поле объясняется при наведении.
- Быстрые действия PNG → JPG и размер 1920 × 1080, добавление настройки в Избранное одной кнопкой и применение сохранённого пресета одним кликом.
- В настройках компоненты FFmpeg, LibreOffice и Calibre устанавливаются по кнопке через WinGet в Windows; после завершения статус проверяется повторно. Полоса прокрутки навигации отодвинута от пунктов.

## 0.9.1 — 2026-10-02

- Новый логотип с драконом для окна, панели задач и установщика; иконки всех разделов и карточек действий.
- Действия автоматически ограничиваются форматами добавленных файлов. PNG предлагает обработку изображения, PDF из изображения и архив; смешанные файлы предлагают общий безопасный вариант.
- Выровнены кнопки и поля на узком окне; добавлены плавные переходы страниц, раскрытия настроек и отклик кнопок с переключателем в настройках.
- Windows тест проверяет логотип и автоопределение PNG внутри упакованного приложения.

## 0.9.0 — 2026-10-02

- Первый проверяемый исходный код desktop-приложения на Python/PySide6.
- Локальная очередь, конвертация мультимедиа и изображений, PDF, ZIP/TAR, пресеты, трей и автозагрузка Windows.
- Генерация VRChat Animated Emoji spritesheet для ручной загрузки на сайте VRChat.
- Windows-сборка и установщик создаются workflow при успешном тегированном выпуске.
